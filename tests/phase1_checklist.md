# Phase 1 manual verification checklist

- [ ] `launch_vex.bat` starts the development app after prerequisites/dependencies are installed.
- [ ] VEX can be dragged using its body.
- [ ] Native window edges resize VEX.
- [ ] VEX remains on top of ordinary application windows.
- [ ] Tray menu shows VEX controls and Show/Hide works.
- [ ] Exit from the click menu, title close, and tray terminates VEX completely.
- [ ] Confirm no VEX startup entry, scheduled task, service, or process remains after exit.
- [ ] Confirm no microphone, vision, network, download, or computer-control activity occurs.
